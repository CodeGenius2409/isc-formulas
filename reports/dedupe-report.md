## Merge rules

- One canonical entry is stored. Its old ids go in `src/data/generated/idAliases.json`, and favourites saved under an old id migrate automatically.
- The longest note among the merged entries is kept. Other names are kept as `aka`, so searching an old name still finds the entry.
- The canonical LaTeX is never rewritten. It is the richest existing form, chosen by hand where the forms differed.
- A repeat in a different unit, subject or class still appears there, drawn from the one stored entry and tagged with where else it appears. Each unit's tables stay complete, and search, favourites and practice each see it once. A repeat within the same unit collapses to one row.

## Semantic pass

Beyond exact matches, I compared all formulas five ways, and read the results rather than trusting the scripts:

1. **Normalised LaTeX**, ignoring the order of `=` sides. This found about three times as many groups as exact matching, mostly Chemistry practical reactions repeated between XI and XII with `_3` written as `_{3}`.
2. **Variable-renamed skeletons**, so `|A+B|²` matches `|a+b|²`. Useful for vector algebra, which is taught in both Physics XI and Mathematics XII.
3. **All same-name groups**, each read individually.
4. **Ranked similar-name and similar-LaTeX pairs.** There were 1,411 candidate pairs. I read the top 330. Most were legitimately different sign variants, such as `sin C + sin D` and `sin C − sin D`, but true repeats were still turning up at the end of that range.
5. **Every pair across classes and subjects.** Because of that, I compared every remaining cross-class and cross-subject pair by LaTeX tokens. All 79 pairs with token similarity of at least 0.8 were read, which found 32 more repeats.

**What this does not cover:** the 1,081 lower-ranked pairs from step 4 were not read individually, and repeats inside one class that differ by more than the thresholds above would not have surfaced. A few repeats may remain, most likely among long reaction equations written differently. If you spot one, add it to `MERGE`.

Findings worth knowing:

- `normalizeLatex` first treated `\\cdot` and `\\times` as equal, which wrongly matched "Dot product is distributive" with "Cross product is distributive". It now keeps them apart on vectors.
- "Percentage error" (`p-xi-1-11`) and "Percentage error (product/quotient)" (`p-xi-1-5`) were kept separate. The first is the definition and the second is the propagation rule, so they are not repeats. See the review file.
- `c-xi-2-124` and `c-xii-6-3` disagree about the d-block configuration (`ns⁰⁻²` and `ns¹⁻²`), and nitration of benzene is given at two different temperatures. Both are in the review file instead of being merged, since merging would silently pick one.
